# 副業 確定申告シミュレーター

会社員の副業(事業所得・青色申告)向けに、ブラウザだけで完結する確定申告の試算ツールです。
サーバ送信はなく、入力内容はブラウザの localStorage にだけ保存されます。

## 使い方

GitHub Pages で公開した `index.html` を開くか、`index.html` をローカルでブラウザに読み込みます。

1. 年分と青色申告特別控除の区分を選ぶ
2. 源泉徴収票の数字を入れる
3. 月別売上と経費(按分%付き)を入れる。銀行・カード明細CSVの取り込みも可
4. 還付/納付額、3パターン比較、決算書・申告書への転記額、チェックリストを確認する

## 構成

```
index.html      ツール本体(HTML + CSS + JS)
css/style.css   ベーススタイル(関西介護ナビと共通)
```
